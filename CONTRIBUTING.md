# Contributing

Want to contribute? Awesome.

## What you need

- Go >= 1.26.0
- A Cup of coffee

## How you can contribute?

1. Fork the repo and `git clone` your fork
2. Install git hooks for local formatting and linting:
   ```
   go tool lefthook install
   ```
4. Read the [Architecture Guide](docs/ARCHITECTURE.md) to understand the codebase structure.
5. Make your changes and commit
6. Push your changes and submit a PR!
